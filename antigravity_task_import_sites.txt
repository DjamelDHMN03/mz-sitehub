J'ai un dossier OneDrive avec un sous-dossier par site télécom, ici :

Chaque sous-dossier de site (ex: "AL2238 Kourifa El Harrache") contient :

- un fichier Excel appelé "doc B" (nommé genre docb_XXXXX.xlsx)
- un PDF d'APS

Je veux importer automatiquement les données de tous les "doc B" dans la

STRUCTURE DU FICHIER "doc B" (Excel, feuille "Feuil1", même mise en page
sur tous les fichiers) -- mapping cellule -> donnée :
- A5 : Site ID (ex: AI4347)
- F5 : Candidat
- H5 : Nom du site
- B9 : Région
- B10 : Wilaya
- B11 : Daïra
- B12 : Commune
- H9 : Négociateur
- H10 : N° portable négociateur
- H11 : Société
- H12 : Date de la visite
- A17 : Adresse du candidat
- A20 : Nom du propriétaire
- K25 : Longitude WGS84
- K26 : Latitude WGS84
- A47 : Type de site (ex: GF)
- A50 : Type d'environnement (ex: URBAIN)
- A53 : Sécurité de la zone (ex: OUI)
- Zone A23-A33 (colonne D) : Type de propriété, coché par un "x" dans la
  colonne C ou D à côté du bon libellé (Propriétaire unique, Co-propriété
  avec/sans syndic, Indivision, Entreprise étatique/privée, Contrat cadre,
  APC, Domaines, Forêts, Autre)
- Zone E84-E86 : possibilité connexion réseau Sonelgaz, coché par un "X"
  en colonne F à côté du bon libellé (<25m / 25-600m / >600m)

SCHÉMA API CIBLE (POST /sites, schéma SiteCreate d'après Swagger) :
- name (string) <- Nom du site
- code (string, 2-32 car., requis) <- Site ID
- wilaya_id (int) <- doit être résolu depuis le nom de wilaya via un
  endpoint de référence (GET /wilayas ou équivalent, à découvrir dans
  Swagger)
- commune_id (int) <- pareil via GET /communes
- address (string) <- Adresse du candidat
- latitude / longitude (float)
- site_type (string) <- Type de site
- owner_name (string) <- Nom du propriétaire
- organisme (string) <- Société
- status_id (int, requis) <- à déterminer via GET /statuses (prendre un
  statut "Nouveau" ou "En prospection" par défaut, à me confirmer si
  ambigu)
- priority (int 1-3, optionnel)
- next_action, observation (string, optionnels)
- is_favorite (bool, optionnel)
- custom_fields (objet JSON libre) <- mets ici TOUT ce qui n'a pas de
  colonne dédiée : Candidat, Région, Daïra, Négociateur, N° portable,
  Date de visite, Type d'environnement, Sécurité de la zone, Type de
  propriété, connexion Sonelgaz, etc.
