# USER_GUIDE.md — MZ SITEHUB, guide utilisateur

Chaque opération courante expliquée simplement, sans jargon technique.

## Se connecter

1. Ouvrir MZ SITEHUB dans votre navigateur.
2. Saisir votre email et votre mot de passe.
3. Cliquer "Se connecter".

## Ajouter un site

1. Cliquer Sites dans le menu de gauche.
2. Cliquer Nouveau site (si disponible) ou utiliser l'import Excel pour
   une création en masse.
3. Remplir les informations connues (code, nom, wilaya...).
4. Enregistrer.
5. Le site apparaît automatiquement sur la carte si un GPS est renseigné.

## Ajouter un contact sur un site

1. Cliquer Contacts dans le menu.
2. Choisir le site concerné dans la liste déroulante.
3. Cliquer le bouton + à côté de "Contacts".
4. Remplir nom, fonction (DRH, DG, APC...), téléphone.
5. Cliquer Ajouter.

## Enregistrer un appel ou une visite

1. Aller sur Contacts, choisir le site, cliquer sur le contact concerné.
2. Cliquer Nouvelle interaction.
3. Choisir le type (Appel, WhatsApp, Email, Réunion, Visite...).
4. Écrire un résumé, éventuellement une date de relance.
5. Cliquer Enregistrer — la fiche du contact se met à jour automatiquement
   avec la date du dernier contact et la prochaine relance.

## Importer un fichier KMZ/KML

1. Aller sur Carte, cliquer Importer.
2. Glisser-déposer votre fichier .kml ou .kmz.
3. Le système détecte automatiquement les codes de site présents et vous
   propose, pour chacun : le rattacher à un site existant, ou en créer un.
4. Cliquer sur l'action souhaitée pour chaque ligne.

## Uploader un document

1. Aller sur Documents, choisir le site.
2. Glisser-déposer le fichier.
3. Si le nom du fichier contient le code du site et un mot-clé reconnu
   (ex : AL6328_APS_V2.pdf), la catégorie et la version sont détectées
   automatiquement.
4. Si le système ne reconnaît pas la catégorie, il vous la demande —
   choisissez-la et confirmez.

## Partager un document

1. Sur Documents, cliquer l'icône de partage à côté du fichier.
2. Un lien sécurisé est généré (valide 7 jours par défaut).
3. Cliquez sur WhatsApp, Telegram ou Outlook pour ouvrir directement un
   message pré-rempli avec ce lien — vous restez libre de l'envoyer ou non.

## Créer un contrat

1. Aller sur Contrats, choisir le site.
2. Cliquer + pour ajouter un contrat.
3. Remplir les champs connus — laisser vide ce qui n'est pas encore connu
   (le montant, par exemple, affichera "À COMPLÉTER" tant qu'il n'est pas
   renseigné, jamais un chiffre inventé).
4. Ajouter les signataires (propriétaire et Ooredoo) séparément.

## Utiliser l'Assistant IA

1. Cliquer MZ Assistant dans le menu.
2. Taper une question, par exemple : "Sites bloqués", "Résume AL6328",
   "Contrats qui expirent bientôt".
3. Pour demander une action (ex : "Ajoute Untel comme DRH de AL6328"),
   l'Assistant demande toujours de confirmer avant d'enregistrer quoi
   que ce soit.
4. Pour rechercher dans le contenu de vos documents PDF indexés, cocher
   "Rechercher dans les documents" avant de taper la question.

## Voir l'historique d'un changement

1. Cliquer Historique dans le menu.
2. Filtrer par type d'élément (site, contact, document...) si besoin.
3. Chaque ligne montre qui a fait quoi, quand, et l'ancienne/nouvelle valeur.

## Exporter un rapport

1. Cliquer Rapports.
2. Pour une liste de sites : choisir les filtres, cliquer Excel ou CSV.
3. Pour la fiche complète d'un site : le choisir dans la liste, cliquer
   "Fiche PDF" (logos, infos, contacts, documents, contrats) ou "Export
   complet" (un fichier ZIP avec tous les documents du site).
